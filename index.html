Architecture
What it's built on
Every layer in production, no placeholders in the stack.
Backend
FastAPI + Uvicorn
Async ASGI. WebSocket broadcast, REST endpoints, rate limiting via slowapi.
Realtime
WebSocket (wss://)
Live device state broadcast to all connected dashboards. Per-connection error handling.
Database
Neon Postgres
Circular buffer per device (500 rows). Emergency tables with 5-min pre-trigger context.
Auth
API Key + WS Token
X-API-Key header for REST, ?token= param for WebSocket. Currently in dev mode.
Hosting
Render (free tier)
Auto-deploy on push to main. HTTPS + WSS out of the box.
Frontend
Vanilla HTML/CSS/JS
No framework. Leaflet.js for maps. GitHub Pages + custom domain.
Hardware
ESP32 + NEO-6M + SIM800L
GPS + cellular fallback wearable. MPU-6050 for motion context. In progress.
Intelligence
Context engine
Speed → stationary / walking / running / vehicle. 30s + 90s auto-escalation tiers.
